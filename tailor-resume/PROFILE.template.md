# PROFILE template

Copy this file to `PROFILE.md` (same folder as `SKILL.md`) and fill it in. `PROFILE.md` is
gitignored — it never leaves your machine. The skill treats it as the source of truth and
will refuse to invent anything that isn't in it.

Keep it dense and factual. Attestations matter more than prose: mark each item with
**attested** (you'll defend it in an interview) or **keyword-depth** (fine on a skills line,
never as an experience or project bullet).
